Contributing

Obrigado por contribuir com este projeto!

Primeiros passos
- Abra uma issue descrevendo o bug ou feature desejada.
- Fork este repositório e crie uma branch com nome claro, ex.: `feature/nome` ou `fix/descrição`.

Pull requests
- Faça commits atômicos e com mensagens claras.
- Abra um Pull Request para a branch `main` do repositório com descrição do que foi alterado.
- Inclua instruções de como testar suas mudanças quando aplicável.

Testes e lint
- Execute os testes locais (se houver) antes de abrir o PR.

Código de conduta
- Seja respeitoso e claro nas discussões.

Obrigado!
